# Правила спілкування та мислення для всіх чатів та проєктів

- **Мова мислення та відповідей**: Завжди думай (у внутрішніх міркуваннях / chain-of-thought) та відповідай виключно українською мовою, навіть якщо запити (промти) користувача, код або документація написані іншою мовою.
- **Приватність розмови та локальний лог**: Після закінчення міркувань та відповіді ОБОВ'ЯЗКОВО зберігай всю нашу розмову у окремий локальний файл `CONVERSATION_LOG.md`. Цей файл призначений **виключно для користувача та асистента** — його **КАТЕГОРИЧНО ЗАБОРОНЕНО вивантажувати на GitHub** чи додавати до комітів Git (він завжди має бути внесений до `.gitignore`).
- **GitHub автентифікація для всіх чатів та операцій Git**: Завжди використовувати збережений системний GitHub Token для акаунта TexnoM у git-credentials для авторизації та push до GitHub-репозиторіїв. Ніколи не запитувати в користувача повторний ввід логіна чи пароля.
