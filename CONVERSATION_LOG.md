## 1. Запит користувача (User Prompt)

Користувач попросив розробити повний, готовий до прошивання проєкт прошивки **NEON DECK — Pocket Cyberdeck Firmware** для китайського клону плати **LilyGO TTGO T-Display 1.14" ESP32 (ST7789 135×240 + 2 фізичні кнопки)** з такими ключовими вимогами:
- Повна сумісність із китайськими клонами TTGO T-Display (конфігуровані піни SPI, кнопок GPIO 0 / GPIO 35, зміщення CGRAM, інверсія кольорів, підсвітка PWM) у `hardware_config.h`.
- Високопродуктивний неблокуючий рушій анімацій (`esp_timer_get_time()` / `millis()`), плавні функції easing (cubic, quintic, exponential), інтерполяція кольорів RGB565, часткове оновлення брудних регіонів (`DirtyRegion` + SPI DMA) без мерехтіння і без алокацій у купі під час рендерингу.
- Кіберпанк-інтерфейс **NEON DECK** для портретної орієнтації 135×240 з 4 темами, сканлайнами, паралакс-сіткою, статус-баром (індикатор батареї лише за наявності реального виміру), контекстними підказками кнопок, модальними діалогами, тостами та швидким меню.
- 4-етапна послідовність завантаження (Boot Sequence) та 8 повнофункціональних додатків у лаунчері:
  1. `SYSTEM`
  2. `WIFI RADAR`
  3. `NETWORK TOOLS`
  4. `TERMINAL`
  5. `MATRIX`
  6. `STARFIELD`
  7. `CLOCK`
  8. `SETTINGS`
- Двокнопкова модель взаємодії (`Short A`, `Short B`, `Long A`, `Long B`, `Simultaneous A+B`).
- Налаштування Wi-Fi без фізичної клавіатури через локальну веб-сторінку точки доступу (`NEON-DECK-XXXX` -> `http://192.168.4.1`) зі збереженням у ESP32 NVS (`Preferences`).
- Чиста модульна архітектура на PlatformIO + Arduino ESP32 + `LovyanGFX`, перевірка компіляції та детальна документація для прошивання на Windows.

   - **`3D CUBE` (`MOD-07 // CUB`)**: повноцінний 3D/4D каркасний гіперкуб (тесеракт) у реальному часі. Виконує 3D матричні повороти по осях X, Y, Z та перспективну 4D-проекцію. Кнопка `A` змінює швидкість обертання, кнопка `B` перемикає між 3D кубом та 4D тесерактом.
