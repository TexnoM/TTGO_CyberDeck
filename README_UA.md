# TTGO_CyberDeck — Прошивка кишенькової кібердеки (`v1.2.0-CYBER`)

> 🇬🇧 **[Read documentation in English (README.md)](README.md)**

**TTGO_CyberDeck** — це високопродуктивна мініатюрна операційна система в стилі кіберпанк без мерехтіння екрана, розроблена спеціально для **китайських клонів плати LilyGO TTGO T-Display 1.14" ESP32 (дисплей ST7789 135×240 TFT + 2 фізичні кнопки)**.

---

## Основні можливості

- **Рендеринг через SPI DMA без мерехтіння (Zero-Flicker Engine)**:
  - Пряма передача буфера спрайта `swap565_t` через SPI DMA (`40 МГц`) та високочастотний ШІМ підсвітки (`25 кГц`).
  - М'які фонові сканлайни та промінь сканера тонують лише темні пікселі фону й ніколи не перекривають текст — шрифти залишаються ідеально чіткими та стабільними.
  - **5 різних м'яких кіберпанк-глітчів** на головному екрані: `RGB Chromatic Split`, `Sine Wave Ripple`, `Dual Laser Sync Beam`, `Holographic Data Burst` та `Classic Soft CRT` (перемикаються у `SETTINGS -> GLITCH FX`: `MULTI`, `CLASSIC`, `OFF`).
- **Жодної бутафорії — 100% реальна апаратна телеметрія**:
  - Усі показники (частота ядер, вільна/мінімальна купа SRAM, найбільший неперервний блок пам'яті, MAC-адреса з eFuse, ревізія кристала, FPS, час кадру в мс, RSSI, пакети 802.11 у повітрі, SHA-256 хеші) зчитуються напряму з апаратних регістрів ESP32.
  - Годинник працює **виключно за реальним часом по Wi-Fi** (через NTP-сервери при підключенні до Wi-Fi або миттєву авто-синхронізацію часу з браузера телефона при відкритті веб-панелі `http://192.168.4.1`). До синхронізації по Wi-Fi чесно відображається статус очікування синхронізації та реальний Uptime.
- **12 вбудованих додатків**:
  1. **`SYSTEM` (`MOD-01 // SYS`)** — монітор двоядерного CPU, фрагментації SRAM/Heap, ревізії чипа, MAC-адреси, реального FPS та осцилограф часу останніх 40 кадрів.
  2. **`WIFI RADAR` (`MOD-02 // RAD`)** — неблокуючий сканер мереж 2.4 ГГц із сортуванням за силою сигналу (RSSI), інспектором шифрування (`OPEN/WPA2/WPA3`), виділенням власної мережі та скролбаром.
  3. **`PKT SNIFFER` (`MOD-03 // SNF`)** — пасивний **802.11 монітор трафіку та 13-канальний спектрограф** на базі апаратного проміскусного режиму (`esp_wifi_set_promiscuous`). Відображає пакети/сек (`PKT/s`, `MGMT`, `DATA`), хвилю трафіку в ефірі та завантаженість усіх 13 каналів Wi-Fi з ручним вибором каналу (`A`) або авто-хопінгом (`B`).
  4. **`NET TOOLS` (`MOD-04 // NET`)** — мережеві реквізити (`IP`, `Gateway`, `DNS`) + неблокуючий Ping-сонар на Core 0 (ICMP Echo + TCP SYN/RST probe) із графіком RTT та режимом авто-пінгу.
  5. **`WEB DECK` (`MOD-05 // WEB`)** — вбудований HTTP-сервер із віддаленою веб-панеллю керування (`http://192.168.4.1` або локальний IP плати). Дозволяє з телефона перемикати додатки й теми, бачити живу телеметрію, надсилати текстові Pager-сповіщення на екран плати, налаштовувати Wi-Fi, встановлювати точний час або синхронізувати його в один клік з браузера смартфона.
  6. **`CYBER EYE` (`MOD-06 // EYE`)** — графічний режим віртуального брелока: анімоване кібер-око зі штучним інтелектом (озирається на всі боки, кліпає, змінює режими й настрій `NORMAL`, `AGGRESSIVE`, `SCANNING`, `SLEEP` за кнопкою `B`).
  7. **`3D CUBE` (`MOD-07 // CUB`)** — графічний демо-режим для брелока: плавна 3D wireframe візуалізація та 4D гіперкуб (тесеракт) з перспективною проекцією у реальному часі. Кнопка `A` змінює швидкість, кнопка `B` перемикає режими.
  8. **`TERMINAL` (`MOD-08 // SHL`)** — локальний командний інтерфейс під дві кнопки (`help`, `sysinfo`, `wifi`, `scan`, `ping`, `uptime`, `theme`, `reboot`).
  9. **`MATRIX` (`MOD-09 // MTX`)** — цифровий дощ із налаштуванням швидкості (`1..5`) та щільності потоків (`1..5`).
  10. **`STARFIELD` (`MOD-10 // STR`)** — 3D симулятор польоту крізь зірки з прицільною сіткою HUD та режимом гіперстрибка (`HYPERWARP`).
  11. **`CLOCK` (`MOD-11 // CLK`)** — універсальний годинник: підтримує **ручне встановлення часу кнопками на платі** (затисніть кнопку `B` для входу в редактор), автоматичну синхронізацію по Wi-Fi NTP, або передачу часу з телефона через веб-панель.
  12. **`SETTINGS` (`MOD-12 // CFG`)** — збереження налаштувань у енергонезалежній пам'яті ESP32 NVS (4 неонові теми, яскравість підсвітки, режим глітчів, швидкість анімацій, ліміт FPS, точка доступу Wi-Fi, перегляд розпіновки заліза, скидання до заводських).

## 1. Швидке прошивання (Linux та Windows)

Готові скомпільовані образи прошивки знаходяться в папці [`release/`](release) для миттєвого запису з адреси `0x0`:

### Linux (Однією командою)
Підключіть плату TTGO T-Display кабелем USB та виконайте:
```bash
sudo ./flash_linux.sh
```
Або напряму через `esptool`:
```bash
sudo esptool --chip esp32 -p /dev/ttyACM0 -b 921600 write_flash 0x0 release/TTGO_CyberDeck.bin
```

### Windows (В один клік)
Двічі клікніть на **[`flash_windows.bat`](flash_windows.bat)** і оберіть пункт `[1]`, або виконайте через PlatformIO CLI:
```bat
pio run -e ttgo-t-display-clone -t upload
```

## 2. Як налаштувати Wi-Fi та синхронізувати годинник

1. На платі відкрийте додаток **`WEB DECK`** або **`CLOCK`** (або затисніть **Кнопку B** для відкриття швидкого меню -> **`WIFI AP`**) та увімкніть точку доступу.
2. Підключіться з телефона або ноутбука до Wi-Fi мережі **`TTGO-CyberDeck-XXXX`**.
3. Відкрийте у браузері адресу **`http://192.168.4.1`**.
   - **Миттєва синхронізація годинника**: щойно сторінка відкриється, браузер автоматично передасть точний час вашого телефона на плату по Wi-Fi!
   - **Підключення до домашнього Wi-Fi**: введіть назву (SSID) і пароль вашої мережі Wi-Fi та натисніть **SAVE & CONNECT**. Плата збереже дані в NVS, підключиться до роутера і надалі автоматично синхронізуватиме точний час через NTP-сервери.

## 3. Схема керування двома кнопками

| Натискання | Дія на Головному Екрані (Launcher) | Дія всередині додатків |
| :--- | :--- | :--- |
| **Коротке `A`** (`GPIO 0`) | Наступна картка додатку | Переміщення курсора / зміна каналу / наступна команда |
| **Коротке `B`** (`GPIO 35`) | Відкрити обраний додаток | Підтвердити / виконати дію / перемкнути режим |
| **Довге `A`** (`>520 мс`) | Попередня картка додатку | **Вихід на Головний Екран** (автозбереження налаштувань) |
| **Довге `B`** (`>520 мс`) | Відкрити **Швидке Меню (Quick Menu)** | Відкрити **Швидке Меню** з будь-якого додатку |
| **Одночасно `A + B`** | Миттєва зміна кольорової теми | Миттєва зміна кольорової теми |

## 4. Розпіновка плати (Hardware Pinout)

Налаштовується у файлі [`include/hardware_config.h`](include/hardware_config.h):

| Сигнал / Функція | Варіант A (Стандарт ~95% клонів) | Варіант B (Альтернативний клон) | Макрос у `hardware_config.h` |
| :--- | :--- | :--- | :--- |
| **Дисплей** | ST7789V (IPS 135×240) | ST7789 (135×240) | `TFT_WIDTH_PX` / `TFT_HEIGHT_PX` |
| **SPI MOSI / SCLK** | `GPIO 19` / `GPIO 18` | `GPIO 19` / `GPIO 18` | `PIN_TFT_MOSI` / `PIN_TFT_SCLK` |
| **TFT CS / DC / RST** | `GPIO 5` / `16` / `23` | `GPIO 5` / `16` / `23` | `PIN_TFT_CS` / `PIN_TFT_DC` / `PIN_TFT_RST` |
| **Підсвітка (BL)** | `GPIO 4` (25 кГц ШІМ) | `GPIO 4` | `PIN_TFT_BL` |
| **Зміщення CGRAM (X, Y)** | `X = 52, Y = 40` | `X = 53, Y = 40` | `TFT_OFFSET_X` / `TFT_OFFSET_Y` |
| **Кнопка A (Верхня/Ліва)** | `GPIO 0` (Active LOW) | `GPIO 0` | `PIN_BTN_A` |
| **Кнопка B (Нижня/Права)** | `GPIO 35` (Active LOW) | `GPIO 35` | `PIN_BTN_B` |
| **Вимір батареї ADC** | `GPIO 34` + `GPIO 14` (EN) | Опціонально | `PIN_BAT_ADC` / `PIN_BAT_ADC_EN` |
