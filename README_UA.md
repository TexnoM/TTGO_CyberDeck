**TTGO_CyberDeck** — це вбудована операційна система для китайських клонів та оригінальних плат **LilyGO TTGO T-Display 1.14" ESP32** (дисплей ST7789 IPS 135x240, 2 фізичні кнопки, порт USB-C). Розроблена як функціональний кишеньковий кібердек та естетичний інтерактивний брелок.

## 2. Архітектура та ключові можливості

### Графічний конвеєр та апаратний ШІМ підсвітки
- **DMA конвеєр без мерехтіння**: Швидкісна передача кадрів по SPI DMA на частоті `40 МГц` за допомогою LovyanGFX.
- **Апаратне регулювання яскравості**: Окремий канал контролера ESP32 LEDC на `GPIO 4` із частотою `2 кГц`. Забезпечує плавний дімінг без навантаження на ядра процесора.
- **Мінімалістичний режим сну**:
  - Вмикається автоматично після таймауту бездіяльності (за замовчуванням `20 с`, налаштовується в системі).
  - Яскравість екрана приглушується на 50% для запобігання деградації матриці та економії батареї.
  - На чистому чорному фоні відображається **тільки цифровий час** (`HH:MM:SS`).
  - Жодних зайвих елементів під час сну. Дотик до будь-якої кнопки миттєво повертає повну яскравість та робочий інтерфейс.

### Пам'ять та локалізація
- **Конфігурація у LittleFS**: Налаштування системи (`theme`, `bright`, `sleepTo`, `tzHrs`, `tgtFps`, `lang`) зберігаються у форматі JSON у файлі `/config.json` з резервним копіюванням у NVS.
- **Підтримка української мови**: Повноцінний вивід кирилиці через растрові шрифти високої чіткості. Перемикання мови інтерфейсу (UA / EN) здійснюється в меню налаштувань.
- **Оптимізація під 4MB Flash**: Розмітка розділів та бінарний образ чітко розраховані на стандартну пам'ять `4MB SPI Flash` (повна сумісність з чіпами 4MB та 16MB).

### Модулі кібердека
1. **`СИСТЕМА` (`SYSTEM`)** — Телеметрія двох ядер CPU, залишок оперативної пам'яті SRAM, MAC-адреса, аптайм, напруга акумулятора та стан зарядки.
2. **`WIFI РАДАР`** — Сканер діапазону 2.4 ГГц з індикацією рівня сигналу RSSI, каналів та типу шифрування.
3. **`PKT SNIFFER`** — Монітор активності пакетів 802.11 з розподілом трафіку по 13 каналах.
4. **`NET TOOLS`** — Стан мережевого інтерфейсу та ICMP/TCP пінг-сонар із гістограмою затримки.
5. **`WEB DECK`** — Вбудована HTTP веб-панель (`http://192.168.4.1`) для перегляду телеметрії та синхронізації часу зі смартфона.
6. **`CYBER EYE`** — Інтерактивне кібернетичне око-вихованець із процедурною анімацією та зміною емоцій.
7. **`3D CUBE`** — Проекція 3D каркасного куба з лічильником FPS та часом рендерингу кадру.
8. **`TERMINAL`** — Локальний термінал із набором вбудованих команд (`help`, `sysinfo`, `wifi`, `ping`, `cat`).
9. **`MATRIX`** — Цифровий дощ із налаштуванням швидкості та щільності символів.
10. **`STARFIELD`** — 3D-симулятор польоту крізь космічний зоряний простір.
11. **`ГОДИННИК` (`CLOCK`)** — Точний цифровий годинник: підтримує ручне встановлення часу кнопками, NTP-синхронізацію по Wi-Fi або передачу часу з браузера телефона в один клік.
12. **`НАЛАШТУВАННЯ` (`SETTINGS`)** — Зміна неонових тем, яскравості, таймауту сну, перемикання мови (UA/EN), запуск точки доступу та апаратна інформація.

## 3. Таблиця розпіновки плати

Конфігурація знаходиться у файлі [`include/hardware_config.h`](include/hardware_config.h):

| Функція | Вивід (GPIO) | Призначення |
| :--- | :--- | :--- |
| **TFT MOSI** | `GPIO 19` | Лінія даних VSPI MOSI (40 МГц) |
| **TFT SCLK** | `GPIO 18` | Тактова лінія VSPI SCLK |
| **TFT CS** | `GPIO 5` | Вибір чіпа дисплея (Active LOW) |
| **TFT DC** | `GPIO 16` | Вибір режиму Дані / Команда |
| **TFT RST** | `GPIO 23` | Апаратне скидання дисплея |
| **TFT BL** | `GPIO 4` | Підсвітка матриці, апаратний LEDC ШІМ (2 кГц) |
| **Кнопка A** | `GPIO 0` | Навігація / Гортання (Active LOW) |
| **Кнопка B** | `GPIO 35` | Дія / Вибір (Active LOW) |
| **ADC Батареї** | `GPIO 34` | Вимірювання напруги через дільник 100k/100k |
| **ADC Enable** | `GPIO 14` | Керування живленням вимірювального дільника |

> [!IMPORTANT]
> **Примітка щодо синього світлодіода біля USB**: Маленький синій світлодіод біля роз'єму USB-C підключений напряму до виводу `CHRG` мікросхеми контролера заряду `TP4054`, а не до мікроконтролера ESP32. Якщо плата підключена лише по USB без акумулятора в гнізді JST, розімкнене коло спричиняє швидке мерехтіння (10–20 Гц). Це є фізичною особливістю роботи аналогового контролера зарядки.

## 4. Керування двома кнопками

Інтерфейс оптимізовано під дві фізичні клавіші:

| Дія | У меню додатків (Launcher) | Всередині додатків |
| :--- | :--- | :--- |
| **Коротке A** | Наступна картка додатка | Переміщення вибору / перехід по списку |
| **Коротке B** | Запуск обраного додатка | Дія / Зміна значення / Підтвердження |
| **Довге A** (`>520 мс`) | Попередня картка | **Вихід у Головне меню** (автозбереження) |
| **Довге B** (`>520 мс`) | Швидке меню (Quick Menu) | Швидке меню з будь-якого екрана |
| **Одночасно A + B** | Швидка зміна колірної теми | Швидка зміна колірної теми |

## 5. Збірка та прошивка

### Варіант А: Швидка прошивка готового образу (Linux)
```bash
# Підключіть пристрій через USB кабель
sudo ./flash_linux.sh
```
Або через `esptool`:
```bash
sudo esptool --chip esp32 -p /dev/ttyACM0 -b 921600 write_flash 0x0 release/TTGO_CyberDeck.bin
```

### Варіант Б: Збірка з вихідного коду через PlatformIO
```bash
# Клонування репозиторію
git clone https://github.com/TexnoM/TTGO_CyberDeck.git
cd TTGO_CyberDeck

# Збірка під цільову конфігурацію 4MB Flash
pio run -e ttgo-t-display-clone

# Запис прошивки в плату
pio run -e ttgo-t-display-clone -t upload
```
